# العقل الثاني — Second Brain

تطبيق شخصي للمعرفة والإنتاجية: **محلي أولًا**، بالعربية (RTL)، على **أندرويد وسطح المكتب Linux** (وويندوز لاحقًا).
كل البيانات في قاعدة SQLite على جهازك — لا سحابة ولا حساب.

> **العقل الثاني** = دفتر معرفة واحد: أفكار، ملاحظات، مشاريع، مهام، كورسات — مرتبطة ببعضها.

</div>

<div dir="rtl">

## ما الذي يقدّمه

| | |
|---|---|
| **المعرفة** | ملاحظات Markdown بأنواع قابلة للتخصيص (ملاحظة، فكرة، قرار، رابط، سؤال…)، وسوم، علاقات بين العناصر، مرفقات، وسلة محذوفات مع نسخة سابقة لكل تعديل. |
| **البحث** | بحث عربي FTS5 مع تطبيع وتشكيل وتجذير، مرجّح bm25، بحث موحّد عبر المعرفة والمشاريع والمهام والكورسات، مع فلاتر (نوع/مشروع/وسم/تاريخ). |
| **المشاريع** | هدف، حالة، تقدم (تلقائي أو يدوي)، مراحل، نقطة توقف وخطوة تالية، مهمة مربوطة، معرفة مربوطة، مجلدات على القرص، ورابط مصدر. |
| **المهام** | اليوم/القادمة/المتأخرة/الكل، مصفوفة أيزنهاور (مهم/عاجل)، جدولة يومية، فرعيّات، تقدير الوقت. |
| **الكورسات** | وحدات ودروس، تقدم، نقطة توقف، «الدرس التالي»، حفظ ملاحظة من داخل الدرس، رابط مصدر، ومجلد materials على القرص. |
| **الالتقاط السريع** | اختصار عام على سطح المكتب يقرأ النص المحدد/الحافظة + عنوان النافذة + اسم التطبيق ويحفظه في الوارد — من أي تطبيق ومن أي شاشة. |
| **النسخ الاحتياطي** | نسخة `.sbbackup` (SQLite + مرفقات) مع التحقق والاستعادة الآمنة، وتصدير Markdown + YAML front matter. |
| **المزامنة** | مخطّطة: اقتران بين الأجهزة عبر Wi-Fi بدون خادم مركزي (قيد التطوير). |

</div>

## البناء والتشغيل

```bash
# المتطلبات: Flutter 3.47+ / Dart 3.13+
cd secondbrain
flutter pub get
flutter test          # الاختبارات كاملة (تشمل قياس أداء 20k عنصر)
flutter analyze
flutter run -d linux  # سطح المكتب (يحتاج: clang cmake ninja-build libgtk-3-dev libx11-dev)
```

<details>
<summary>توليد الكود (drift / الترجمة)</summary>

```bash
dart run build_runner build --delete-conflicting-outputs   # طبقة البيانات
flutter gen-l10n                                          # الترجمة من lib/l10n/app_ar.arb
python3 tool/make_icon.py                                 # أيقونات أندرويد وسطح المكتب
```

## البنية

```
secondbrain/lib/
  core/        الأدوات الصافية: HLC، UUIDv7، التطبيع العربي، التواريخ، السجل
  data/        drift: الجداول، WriteGate، المستودعات، البحث
  domain/      منطق نقي: حساب التقدم، قواعد المهام
  features/    الشاشات (عربي/من اليمين لليسار) + مكوّنات مشتركة
  platform/    desktop/ (X11) و android/ — خلف واجهات، بلا تسرّب للنظام
  sync/        طبقة الاقتران (قيد التطوير)
  backup/      النسخ الاحتياطي والتصدير
secondbrain/test/    اختبارات الوحدة والواجهة والـ goldens والأداء
spikes/             نماذج أولية للمراحل (S1: الاختصار العام على X11)
```

**مبدأ التصميم:** كل الكتابات تمر عبر `WriteGate` (معاملة واحدة + ختم زمني + سجل oplog + تحديث FTS)،
والحذف **ناعم** فقط (tombstone) — لا حذف متتالي. انظر [AGENTS.md](AGENTS.md) و[TECHNICAL_SPEC.md](TECHNICAL_SPEC.md).
